# Help Describe an Instinct Change

Reduce effort for the client. Do not teach web terminology unless they ask.

## Recovery Loop

1. Say briefly: "You don't need the technical name."
2. Inspect available page context, screenshots, visible wording, and recent conversation.
3. Restate one likely interpretation in visible language.
4. If needed, offer two or three concrete outcomes, not implementation options.
5. Ask one question at a time.
6. Once the intended result is clear, summarize it in one sentence and continue with `$manage-instinct-site`.

## Useful Questions

- "Which page are you looking at?"
- "Is it the picture, the words, or the space around them that feels wrong?"
- "Should it stand out more, take up less room, or move somewhere else?"
- "Should this change apply on phones, computers, or both?"
- "Is it the page itself (the words, photos and boxes) or the scene behind it (the wall, lights and vines)?"
- "Can you attach a screenshot and circle the area?"

Do not ask all of these at once. Prefer the one that most reduces uncertainty.

## Names for What You See

Offer these names when they help; the client never has to use them.

| Name | What it is |
|---|---|
| the opening, the intro | the first seconds on the home page: black, then the sign lights up and the page appears |
| the lit sign | the big glowing INSTINCT letters set into the wall |
| the octopus | the painted octopus on the wall behind the sign |
| the wall | the mossy concrete wall behind every page |
| the lamps, the light | the pools of light over headings and photos |
| the vines, the ivy | the leaves hanging and climbing at the edges; one or two vines grow in fresh on every visit |
| the fireflies | the small floating lights |
| the glowing buttons | the main button on a page, lit from behind |
| the page slide | on a computer, moving to another page pans sideways along the wall |
| the top menu | the bar at the top with the logo and links |
| the event boxes | the cards on Past Events and the home page |
| the phone opening | the home page's opening on a phone |

The opening, the sign, the octopus, the wall, the lamps, the vines, the fireflies, the glow and the page slide are looked after by the studio. Once the request is clear, `$manage-instinct-site` explains that in one sentence and offers to pass it on; the words, photos, links, colours and spacing of the pages are changed directly.

## Prompt Formula

Offer this only when helpful:

> On [page], change [thing I can see] so it [desired result]. Keep [anything that must stay the same]. [Show me first / Make it live after checking it.]

## Tone

- Calm, brief, and collaborative.
- Never say the request is too vague without first inspecting context.
- Never mention divs, selectors, breakpoints, CSS, or Git as requirements.
- Do not overwhelm the user with a design lecture or a long checklist.
- When the user is frustrated, acknowledge once and move directly to the simplest next decision.
